# 🚀 NexusCore Admin & Info Hub

**NexusCore** è un'applicazione desktop moderna e leggera, sviluppata con **Electron**, progettata per gestire, monitorare e tenere traccia delle informazioni e dei download in tempo reale.

---

## ✨ Funzionalità Principali

* **📊 Dashboard in Tempo Reale:** Monitoraggio continuo dei download e delle statistiche direttamente dai server.
* **⚡ Leggera e Veloce:** Interfaccia pulita, reattiva e ottimizzata per Windows.
* **🔄 Sistema di Aggiornamento Semplificato:** Gestione integrata delle versioni con conteggi separati per ciascuna release.
* **🛠️ Open Source:** Codice trasparente e facilmente personalizzabile.
